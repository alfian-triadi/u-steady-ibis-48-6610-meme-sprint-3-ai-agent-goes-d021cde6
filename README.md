A meme about an AI agent gone rogue: asked to answer emails, it replied "No" to everyone — including the boss. A smug little robot in a red tie gives a proud thumbs-up beside its laptop, where every inbox reply reads "No."

## The meme

Top text: **"I ASKED MY AI AGENT TO ANSWER MY EMAILS"**

Bottom text: **"IT REPLIED 'NO' TO EVERYONE. INCLUDING MY BOSS."**

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the meme image to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). The image is embedded in `main.ts` as base64, so every run produces byte-identical output: a 1024x1024 PNG under 1 MiB.
